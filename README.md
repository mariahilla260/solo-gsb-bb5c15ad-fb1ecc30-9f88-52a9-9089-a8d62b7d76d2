# 🌿 植物显微切片测量 Web 应用

在浏览器中对植物显微切片图片进行像素定标，圈选多个细胞外轮廓及各自的孔洞，
自动计算**扣除孔洞后的面积（µm²）**与**含孔洞边界的总周长（µm）**，
并可将测量冻结为不可变报告，导出标注 PNG 与测量 CSV。

- 后端：Node.js + Express + SQLite（better-sqlite3）+ sharp
- 前端：原生 Canvas（零构建），图片与数据库全部保存在本地 `data/`
- 一键启动：Docker / Docker Compose

---

## 一、功能说明

### 定标
1. 上传 PNG / JPEG / WebP 显微图片（原图保存在本地，不做任何缩放重采样）。
2. 选择「📏 定标」工具，在原图标尺两端**各点击一个不同像素点**，填写两点间的**实际距离（微米 µm）**。
3. 应用得到换算系数 `µm/px`。两个像素点重合、微米距离 ≤ 0 都会被拒绝并指出原因。
4. **重新定标**时，所有草稿轮廓的像素形状保持不变，面积与周长自动按新比例重算；
   **已发布报告不受影响**（报告冻结发布时的图片、标尺、轮廓和结果）。

### 圈选细胞与孔洞
- 「⭕ 圈细胞」：逐点点击描绘外轮廓，双击 / Enter / 点击起点闭合。
- 「⬡ 圈孔洞」：先在右侧列表或画布选中所属细胞，再描绘孔洞。
- 可创建多个细胞；每个细胞可有多个孔洞。

保存或发布时，服务端强制执行以下规则，**任一不通过则整次修改不生效**，并指出具体对象：

| 规则 | 错误提示对象 |
| --- | --- |
| 轮廓至少 3 个顶点、不允许重合顶点 | 对应细胞/孔洞 |
| 轮廓不得自交（边相交或共线重叠） | 对应细胞/孔洞 |
| 顶点不得越出图片范围 | 具体顶点坐标 |
| 孔洞必须**严格位于**所属细胞外轮廓内（不得穿越、触碰边界） | 对应孔洞 |
| 同一细胞内的孔洞边界之间**不得接触**（不得相交、相切、共边） | 对应两个孔洞 |
| 标尺微米距离必须为正数、两个像素点必须不同 | 标尺 |

### 测量口径
- 面积 = 外轮廓面积 − Σ 孔洞面积，单位 **平方微米（µm²）**
- 总周长 = 外轮廓周长 + Σ 孔洞周长（含孔洞边界），单位 **微米（µm）**
- 所有几何坐标均为**图像像素坐标**；滚轮缩放、右键/中键拖动平移只改变显示视图，**测量值不变**。

### 版本控制（乐观锁）
- 每份草稿带递增 `version`。保存草稿、发布报告都必须携带**读取时的草稿版本**。
- 若期间草稿被改过（版本过期），服务器返回 `409` 拒绝覆盖，前端自动重新加载最新草稿。
- 发布成功后生成**不可变快照**：独立的图片副本、标尺、轮廓、测量结果与草稿版本号。

### 导出
- 单个报告：标注 PNG（原图叠加彩色细胞、红色虚线孔洞、编号、标题、比例尺）+ 测量 CSV（UTF-8 BOM，Excel 可直接打开）。
- 多选报告导出 ZIP：每份报告一个目录（原图、标注 PNG、CSV、快照 JSON），外加汇总 `all-measurements.csv`。

## 二、配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 容器内服务监听端口 |
| `HOST_PORT` | `8080` | Compose 映射到宿主机的端口（`HOST_PORT=9000 docker compose up`） |
| `MAX_UPLOAD_MB` | `50` | 单张上传图片大小上限（MB） |
| `DATA_DIR` | `/app/data`（容器内） | SQLite、上传原图、报告快照的本地保存目录 |

本地裸跑时还可用 `DB_PATH` 指定数据库文件路径（默认 `$DATA_DIR/app.db`）。

数据目录结构（首次启动自动创建）：

```
data/
├── app.db              # SQLite 数据库（自动建表初始化）
├── uploads/            # 上传的原始图片
└── reports/            # 发布报告时复制的图片快照
```

## 三、启动命令

### 方式 A：Docker Compose（推荐，一条命令）

```bash
docker compose up -d --build
```

启动后访问：

> **http://localhost:8080**

宿主机端口被占用时：

```bash
HOST_PORT=9000 docker compose up -d --build
# 访问 http://localhost:9000
```

停止：

```bash
docker compose down
```

### 方式 B：本地 Node.js 运行

要求 Node.js ≥ 20。

```bash
npm install
npm start
# 访问 http://localhost:8080
```
